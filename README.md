# Robot-arm
ENGR100-400 class project, team Helious
The repo includes the files related to the robot arm we implemented on our rover. Files covering:
- 3D STEP model of the arm for 3D printing 
- Arduino. ino file can be flashed to an Arduino Nano board to control servo motion
- Python program runs on the host computer to calculate inverse kinematics and send commands through the serial port
